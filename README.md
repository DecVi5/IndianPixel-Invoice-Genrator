# Indian Pixel Studio — Financial & Invoice Suite

An executive-tier invoice generator and revenue health ledger built for **Indian Pixel Design Studio**, featuring the official origami aperture brand mark, statutory Indian GST & PAN compliance, 3-phase milestone disbursements, and UPI instant clearance.

![Indian Pixel Suite](public/favicon.svg)

---

## Key Features

- **Brand-Authentic Identity**:
  - Embedded geometric origami aperture star mark in high-contrast Midnight Green (`#08221B`) and Gunmetal (`#2C3330`) badges.
  - Strict 5-color palette: Midnight Green (`#08221B`), Gunmetal (`#2C3330`), Camouflage Green (`#ACBEA3`), Amber Yellow (`#FFA400`), and Linen (`#F8F4ED`).
  - Polished Apple-standard typography (Montserrat Alternates, Poppins, and Space Mono).

- **Invoicing Architecture**:
  - **Single Settlement (100%)**: One-time full invoice payments.
  - **3-Phase Milestones (40% — 40% — 20%)**: Advance kickoff, mid-project design delivery, and final source handoff.
  - **Dynamic UPI QR Code**: Instant mobile payments via VPA (`theindianpixel@okaxis`).
  - **Indian Statutory Compliance**: Pre-configured with Section 22 CGST Act exemption and studio PAN (`KJKPD8069P`).
  - **High-DPI PDF & Print**: Pixel-perfect A4 sheet geometry (`210mm x 297mm`).

- **Studio Ledger & Analytics**:
  - Real-time billing velocity and cashflow tracking.
  - Contracted billings vs realized cash inflows breakdown.
  - Interactive Recharts cashflow graphs.

- **Responsive Ergonomics**:
  - Desktop-optimized workspace with persistent left navigation sidebar.
  - Apple-style slide-over navigation drawer for mobile phones and tablets.
  - Emil Kowalski motion tokens with reduced-motion accessibility.

---

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Charts**: Recharts
- **PDF & Print**: html2canvas-pro & jsPDF
- **QR Engine**: qrcode

## Quick Start

```bash
# Clone the repository
git clone https://github.com/DecVi5/Invoice-generator-Indian-Pixel.git
cd Invoice-generator-Indian-Pixel

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:3000` in your browser. Default studio unlock code is `12345678`.
